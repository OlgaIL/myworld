# API Яндекс Метрики для админки

Админка может показывать количество визитов по сохранённому ClientID пользователя. Если API выключен или временно недоступен, список пользователей продолжает работать и показывает `—`.

## Настройки сервера

Добавьте в `server/.env`:

```ini
YANDEX_METRIKA_API_ENABLED=true
YANDEX_METRIKA_COUNTER_ID=109386353
YANDEX_METRIKA_VISITS_START_DATE=2026-01-01
YANDEX_METRIKA_API_TOKEN=OAuth-токен-с-правом-чтения-Метрики
```

Для OAuth-приложения достаточно права `metrika:read`. Токен хранится только на сервере и не передаётся клиенту.

После изменения `.env` перезапустите сервер через PM2 и откройте в админке раздел настроек. В карточке «Аналитика» должны отображаться статусы «включен» и «настроен».

## Что показывает счётчик

Число визитов рассчитывается Метрикой с даты `YANDEX_METRIKA_VISITS_START_DATE` по сохранённому ClientID. ClientID относится к конкретному браузеру, поэтому визиты того же человека с другого браузера или устройства в это число не входят.

Кнопка «Вебвизор» копирует ClientID и открывает Вебвизор. Вставьте скопированный ClientID в фильтр Метрики для поиска визитов пользователя.
