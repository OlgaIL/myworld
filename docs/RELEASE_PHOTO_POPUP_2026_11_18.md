# Попап фото с увеличением — 18 ноября 2026

По согласованию с Ольгой оставлен обычный попап поверх затемнённой страницы.
Попап теперь всегда по центру, ширина ограничена экраном и 1100px.
Первоначально фото показано целиком. Лупа увеличивает его; увеличенное фото
прокручивается по вертикали и горизонтали внутри окна. Есть уменьшение,
возврат к целому фото, поворот, закрытие кнопкой/Escape/кликом по фону.
Прокрутка страницы на время просмотра блокируется и восстанавливается
при закрытии. Переработанный режим сравнения полностью откачен.

Файлы: `Modal.jsx`, новый `Modal.css`, расчёт `imageRotation.js` и его тесты.
Изменения обработки реквизитов и многостраничности в эту правку не входят.
OCR/LLM при просмотре фото не вызываются.

Проверено: 6 тестов геометрии, адресный ESLint, сборка клиента;
Browser Plugin на учебном высоком фото, 1280×720 и 390×844,
масштаб/прокрутка/поворот/«Целиком»/закрытие. Скриншоты:
`work/image-viewer-review-2026-11-18/popup-centered-zoom.jpg` и `popup-mobile.jpg`.
Ольга дала команду сделать коммит и пуш 18 ноября 2026. На сервер правку
публикует Ольга; проверку после публикации выполняет она же.

После согласованного коммита и пуша, только для этой клиентской правки,
Ольга выполняет на сервере:

```bash
cd /root/myworld
git pull --ff-only origin main
npm run build --prefix client
```

Миграции и перезапуск PM2 для попапа не нужны. Если в общий выпуск включаются
серверные изменения обработки или многостраничности, нужны их отдельные шаги.
Проверка после обновления страницы: открыть существующее фото, увеличить,
прокрутить в обе стороны, повернуть, показать целиком и закрыть.
