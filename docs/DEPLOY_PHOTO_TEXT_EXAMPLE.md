# Общая публикация: промостраница и Microsoft Clarity

Локальная правка от 15 октября 2026 года. Используются общие стили примеров
со страницы `/handwriting-to-text`. Полное фото открывается в модальном окне;
закрытие — крестик, Escape или фон. На узких экранах фото и текст расположены
друг под другом. Исходный текст распознавания сохранён. Подпись и разделительная
линия занимают ширину сравнения.

16 октября в общий состав включена подготовленная интеграция Clarity:
контроллер и компоненты запуска/защиты маршрутов, отдельное согласие,
маскирование документов и личных данных, политика, клиентские тесты,
`docs/CLARITY.md` и соответствующие пункты `docs/ROADMAP.md`.
Project ID — `yy89cpbeew`, только `word2you.ru`, без зеркала, новых событий
и меток. Метрика сохранена. Проверочные SDK, снимки и прочие файлы `work/`,
незавершённые OCR/серверные изменения в этот состав не входят.

Ограничение: URL с query/hash (в том числе UTM) не записываются Clarity.
Обычная промостраница `/photo-to-text` разрешена; адрес с `#how` или другими
параметрами/фрагментом исключён. Неизвестный подробный referrer тоже может
исключить запись. Метрика продолжает работать.

После локальной приёмки и отправки соответствующего коммита в `origin/main`
Ольга выполняет публикацию. До `git pull` проверить вывод `git status --short`:
при неожиданных изменениях остановиться. Использовать актуальную проверенную
резервную копию по `docs/BACKUP_RESTORE.md`.

```bash
cd /root/myworld
git status --short
```

Если рабочая папка чистая, выполнить:

```bash
cd /root/myworld &&
git pull --ff-only origin main &&
npm ci --prefix client &&
VITE_CLARITY_ENABLED=true VITE_CLARITY_HOSTS=word2you.ru npm run build --prefix client &&
git log -1 --oneline
```

Для этого клиентского состава миграции и перезапуски backend/nginx не нужны.
Clarity настраивается переменными сборки, не `server/.env`.
Новые зависимости не добавлены. Серверные файлы и миграции 038/039
в текущем коммите не меняются.

Проверки после публикации выполняет Ольга:

```bash
curl --fail --silent --show-error https://word2you.ru/photo-to-text -o /dev/null
```

После сборки открыть `https://word2you.ru/photo-to-text`, обновить страницу,
проверить сравнение на компьютере и телефоне, открыть фото и закрыть его
крестиком, по Escape и нажатием на фон. Убедиться, что фото целиком и нет
горизонтальной прокрутки. Реальный Recordings, согласие/отзыв, маскирование,
исключение админки и работу Метрики проверить строго по `docs/CLARITY.md`.
Для записи тестового визита использовать чистый URL без query/hash и
искусственные материалы. Агент рабочий сайт не публиковал и не проверял.

Отключить Clarity для новых загрузок, сохранив промостраницу:

```bash
cd /root/myworld &&
VITE_CLARITY_ENABLED=false VITE_CLARITY_HOSTS=word2you.ru npm run build --prefix client
```
