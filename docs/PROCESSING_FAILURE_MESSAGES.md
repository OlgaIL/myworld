# Сообщение после успешного OCR и сбоя оформления — 5 ноября 2026

Ольга согласовала отдельный текст о проблемах со связью. Готово локально,
без коммита и публикации. Полный аудит сообщений в ROADMAP этим не закрывается.

Для сохранённой причины `Timeweb: TIMEWEB_NETWORK_ERROR` или
`Timeweb: TIMEWEB_TIMEOUT` (также поддержаны коды без префикса):

> Текст распознан. Из-за проблем со связью описание и оформление временно недоступны. Обработка не списана. Повторите обработку немного позже.

Для остальных причин, включая HTTP 400 (`TIMEWEB_REQUEST_ERROR`), 401/403, 429,
5xx, некорректный/обрезанный ответ и неизвестную старую ошибку:

> Описание и оформление временно недоступны. Обработка не списана. Попробуйте повторить обработку.

Код ошибки остаётся в служебных данных; название провайдера пользователю не
показывается. Нельзя определять сетевую ошибку по произвольному фрагменту
текста или общей заметке: используются только точные сохранённые коды.

Клиент выбирает сообщение по error, поэтому обновление охватывает прежние
документы, даже если notes содержат старый общий текст. Подключены карточка
кабинета (включая Gallery), гостевая карточка, страницы документа гостя и
вошедшего пользователя, вкладка «Оформленный». Сервер записывает согласованный
текст в aiNotes новых recognized-результатов. Сохранение OCR, статус recognized,
правила повтора и списания обработок не менялись.

Проверены серверные результаты и реальные React-компоненты: 3 серверные проверки
и клиентская проверка соответствия текста, старых заметок и пяти вариантов
отображения. Адресный ESLint и production-сборка прошли. Платных запросов к моделям
и изменений документов пользователей для проверки не выполнялось.

## Публикация после отдельного согласованного коммита — выполняет Ольга

Для этой правки миграций и новых зависимостей нет. Команды относятся только
к согласованному опубликованному коммиту; незакоммиченные изменения не передаются.
Перед pull `git status --short` должен быть пустым.

```bash
ssh root@147.45.246.205
cd /root/myworld
git status --short
git pull --ff-only origin main
cd /root/myworld/client
npm run build
cd /root/myworld
pm2 restart myworld-server --update-env
pm2 status myworld-server
curl -fsS http://127.0.0.1:4000/api/health
```

После Ctrl+F5 Ольга проверяет имеющиеся документы: при сохранённом TIMEWEB_TIMEOUT
или TIMEWEB_NETWORK_ERROR появляется текст о связи; при TIMEWEB_REQUEST_ERROR —
общий. Новые платные ошибки специально не провоцировать. Если вместе публикуются
другие изменения, их миграции и зависимости сверять по отдельным инструкциям.
