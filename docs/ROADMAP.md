## Высокий приоритет

### Формулы

- [ ] Этап 1. Определять наличие формул, не изменяя и не сокращая основной текст.
- [ ] Показывать вкладку `Формулы` только для документов, где формулы действительно обнаружены.
- [ ] Гостю показывать наличие возможности, но саму работу с формулами открывать после входа.
- [ ] Этап 2. Выделять формулы из исходного OCR вместе с контекстом и позицией в документе.
- [ ] Не удалять формулы из вкладок `Текст`, `Исходный` и `Оформленный`.
- [ ] Этап 3. Отображать подтверждённые формулы через KaTeX в безопасном режиме.
- [ ] Отмечать сомнительные формулы как требующие проверки, а не исправлять их молча.
- [ ] Для платных пользователей предложить отдельную кнопку проверки формулы
  дополнительным запросом модели.
- [ ] Добавлять изменения формул в прозрачный список исправлений.
- [ ] Проверить реальные примеры по математике, химии и физике до публикации.

### Полнота и качество текста

- [ ] Вернуться к расширенному промпту Яндекса отдельной задачей.
- [ ] Собрать небольшой постоянный набор сложных изображений для сравнения результатов.
- [ ] Проверять, что после модели не исчезли формулы, реквизиты, последние предложения,
  единицы измерения и значимые фрагменты OCR.
- [ ] Менять правила промпта по одному и сравнивать результат с контрольными примерами.
- [ ] Продумать автоматическую проверку полноты ответа и безопасный повторный запрос,

- [ ] Улучшать оформление абзацев, заголовков и списков без изменения содержания.

## Принятые решения

- Основной текст документа нельзя ухудшать ради таблиц, формул или дополнительного оформления.
- Исходный OCR сохраняется отдельно и остаётся доступным пользователю.
- Формулы нельзя исправлять молча: исходник, изменение и степень уверенности должны быть видны.
- Таблицы и формулы являются функциями авторизованного кабинета.
- Production публикует и проверяет только Ольга по подготовленным и проверенным командам.
- Работа ведётся в одной папке `C:\Users\olgak\PROJECTS\myworld`; отдельные worktree
  создаются только после прямого согласования.
