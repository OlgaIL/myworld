# Прокрутка при переходах между промо — 30 октября 2026

## Причина и исправление

Обычная ссылка между страницами внутри React-приложения сохраняла прежнюю
позицию прокрутки. Локально воспроизведено: ссылка под примерами на
`/batch-photo-to-text` открыла `/handwriting-to-text` с `scrollY=1077`;
заголовок оказался выше видимой области.

`PromoNavigationScroll` при переходе по ссылке на другое промо открывает верх
страницы. Для ссылки с фрагментом открывается соответствующий раздел. «Назад»
сохраняет штатное восстановление позиции. Главная, документы и аккаунт этим
компонентом не управляются. Подключён в `AppShell.jsx`.

## Проверено локально

- Тот же переход: после исправления `scrollY=0`, заголовок виден.
- Кнопка «Назад» вернула страницу нескольких фото на прежние 1077 px.
- Переходы на таблицы, печатный текст, общий обзор и рукопись открываются сверху.
- Якорь `/photo-to-text#batch` продолжает открывать нужный раздел.
- Сборка, шесть пререндеров и все 9 HTTP-проверок SEO прошли; адресный ESLint прошёл.

Доказательства: `work/promo-scroll-2026-10-30/checks.json`, `before.png`, `after.png`.
Production не открывался и не проверялся. Изменение пока локальное.

## Для поисковика страницы разные

Каждому из пяти URL промо соответствует отдельный HTML пререндера, свой title,
description, canonical и содержание. Общие React-компоненты не превращают
разные адреса в один документ для индексирования. Наличие и позиции страниц
в поиске нужно проверять в Вебмастере отдельно.

Яндекс описывает [индексирование JavaScript-страниц](https://www.yandex.ru/support/webmaster/ru/yandex-indexing/rendering)
и [обработку дублей](https://yandex.ru/support/webmaster/ru/robot-workings/canonical).
Схожее содержание может стать причиной объединения дублей; сам общий код
не доказывает ни дублирование, ни ограничение сайта.

На сервере сначала:

```bash
cd /root/myworld
git status --short
```

Если есть незнакомые изменения отслеживаемых файлов — остановиться. Не применять
старые патчи и не сбрасывать файлы. При чистой рабочей копии:

```bash
git pull --ff-only origin main && npm run build --prefix client
```

Это только клиентское исправление: **миграции, npm install и перезапуск PM2
не нужны**. Не переносить всю локальную сборку: в общей папке есть другие правки.

Проверка Ольгой после Ctrl+F5: на странице нескольких фото нажать ссылку
«Распознавание рукописного текста с фото — примеры результата» под примерами.
Открывается начало рукописного промо. Проверить также «Другие задачи», якорь
«Несколько фото» на печатном промо и кнопку «Назад». Опубликованный результат
подтверждает Ольга; локальная проверка не означает публикацию.
