Публикует и проверяет боевой сайт Ольга. Агент готовит локальный код и коммит;
на сервер не подключается.

## Проверка

Новых зависимостей, миграций БД и npm install для выпуска нет.

## 1. На компьютере Ольги

PowerShell:

```powershell
cd C:\Users\olgak\PROJECTS\myworld
git push origin main
ssh root@147.45.246.205
```

Пуш отправляет только коммиты. Остальные незакоммиченные правки папки не попадут
на сервер. Если push завершился ошибкой, к публикации не переходить.

## 2. На сервере — выполняет Ольга

```bash
cd /root/myworld
git status --short
```

Если есть незнакомые изменения в отслеживаемых файлах — остановиться.
Не выполнять git reset, git stash или принудительный pull.
Если ранее уже применялся патч промо, сначала согласовать эти изменения с Git;
повторно накладывать патч или pull поверх них не нужно.

При чистых отслеживаемых файлах:

```bash
git pull --ff-only origin main &&
npm run build --prefix client &&
pm2 restart myworld-server &&
pm2 status myworld-server
```

Символы && останавливают цепочку при ошибке. Перезапуск нужен, потому что
серверный список публичных адресов тоже изменился. Миграции не запускать.

## 3. Проверить после публикации

```bash
git log -2 --oneline
curl -fsS https://word2you.ru/table-from-photo | grep -F '<h1>Таблица с фото'

curl -fsS https://word2you.ru/sitemap.xml | grep -E 'table-from-photo|batch-photo-to-text'
```

Ольге открыть пять промо после Ctrl+F5, проверить ссылки/загрузку/отступы на
телефоне и компьютере. На аккаунте с остатком 186 под загрузкой нет покупки,
баланс и загрузка доступны. Не тратить обработки ради проверки порога.

После проверки написать в текущий маркетинговый чат:
**«Промо опубликованы и проверены»**.
