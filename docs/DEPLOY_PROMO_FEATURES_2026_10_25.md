## Что подготовлено

- `/about`: общий обзор с четырьмя карточками возможностей; сохранены архив,
  поиск и сценарий «телефон → компьютер».

  ссылки на отдельные сценарии.
- `/batch-photo-to-text`: несколько файлов → отдельные записи; очередь,
  вход, остаток обработок, примеры исходных страниц.
- `/table-from-photo`: восстановление/проверка/копирование в Word. Таблица
  на странице — явно подписанная схема, а не доказательство OCR с фотографии.
  Реальную пару «фото → проверенный результат» ещё предстоит добавить.
- Формулы и добавление страниц в один документ помечены как планы.
- Собственные title/description/canonical, пререндер шести страниц,
  новые адреса в sitemap (теперь 11 URL вместо 9), запись новых промо в Clarity
  по существующему согласию; код подтверждения Google Search Console.

Нет изменений БД, новых зависимостей и миграций. Нужны сборка клиента и
перезапуск сервера: серверный список публичных адресов тоже изменён.

## Публикация только этого изменения

В общей папке много чужих незавершённых изменений. Не переносить целиком
локальный `client/dist`, не выполнять `git add .`. Патч сформирован из отдельного
коммита промо и не содержит текущие незакоммиченные изменения OCR/админки.

PowerShell, из `C:\Users\olgak\PROJECTS\myworld`:

```powershell
scp .\work\word2you-promos-2026-10-25.patch root@147.45.246.205:/root/word2you-promos-2026-10-25.patch
ssh root@147.45.246.205
```

На сервере, выполнять последовательно; при ошибке остановиться:

```bash
cd /root/myworld
git status --short
git apply --check /root/word2you-promos-2026-10-25.patch
git apply /root/word2you-promos-2026-10-25.patch
npm run build --prefix client
pm2 restart myworld-server
pm2 status myworld-server
```

Проверка `git apply --check` должна пройти до изменения файлов. Если патч
не применяется, ничего не сбрасывать и не применять с принудительными флагами.
Патч меняет рабочие файлы, не историю Git сервера. Перед следующим `git pull`
эти изменения нужно согласовать с историей, чтобы не получить конфликт.

Открыть три промо на телефоне и компьютере, проверить ссылки и переход
«Загрузить фото»; прежние `/photo-to-text#batch` и `#tables` сохранены.
