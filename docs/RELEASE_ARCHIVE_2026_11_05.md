## Локально после создания коммита — отправка Ольгой

```powershell
cd C:\Users\olgak\PROJECTS\myworld
git push origin main
```

## На сервере — по шагам

```bash
ssh root@147.45.246.205
cd /root/myworld
git status --short
```

Если вывод пустой:

```bash
git pull --ff-only origin main
cd /root/myworld/server
npm run db:status
```

Ожидаемая новая миграция — только `047_document_display_titles.sql`. Если список
отличается, сначала сверить состав публикации. Затем:

```bash
npm run db:migrate
npm run db:status
cd /root/myworld
VITE_INSPECTLET_ENABLED=true VITE_INSPECTLET_HOSTS=word2you.ru npm run build --prefix client
pm2 restart myworld-server --update-env
pm2 status myworld-server
curl -fsS http://127.0.0.1:4000/api/health
```

Новых npm-зависимостей нет. Нужен перезапуск API: меняются названия и удаление.
После Ctrl+F5 Ольга проверяет номера в списке/документе, отмену и удаление
выбранных ненужных записей, неизменный остаток обработок. Для проверки сообщений
достаточно существующих ошибок, новые платные отказы специально не вызывать.
Inspectlet начинает запись после согласия и только на разрешённых маршрутах:
подтверждение новой записи — по INSPECTLET.md. Метрика остаётся подключённой.

Публикация и проверка production этим документом не подтверждаются.
