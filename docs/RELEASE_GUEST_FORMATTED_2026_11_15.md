# Скрытие точного дубля «Оформленного» у гостя

15 ноября Ольга поручила распространить осторожное скрытие дубля на гостя.
После проверки на обычном localhost она сообщила «все сработало» и разрешила
отдельный коммит. Публикация и production-проверка остаются за Ольгой.

Гостевой API вычисляет `formattedIsRedundant` по сохранённому оформлению и
публичному тексту с текущими исправлениями. Сравнение буквальное, с теми же
границами paragraph. Учитывается прежнее превращение названия в заголовок.
Правила сравнения и превращение названия общие для сервера и клиента.

Только явный `true` скрывает у гостя вкладку и приглашение войти ради неё.
Heading, list, table, table_source, неизвестные типы/поля, отличия буквального
текста, незавершённая обработка и признаки/ожидание таблиц сохраняют вкладку.
Отсутствующие или пустые blocks не доказывают дубль. Прежний fallback вошедшего
пользователя сохранён; его доступ к оформлению не меняется.

Гостевой ответ возвращает `formattedContent: null`: закрытые блоки для проверки
видимости не требуются. Тексты, исправления и оформление в БД не переписываются.
Ссылка из готовых таблиц на «Оформленный» остаётся корректной: готовые таблицы
исключают скрытие этой вкладки. Если выбрана скрытая вкладка, показывается «Текст».

## Проверки

- 29 серверных проверок: признак, закрытые блоки, полезная/неизвестная структура,
  состояния обработки/таблиц, точное сравнение и сохранение исходных данных.
- 89 клиентских проверок: реальный компонент и гостевой hook через React SSR,
  сценарии до/после входа, отсутствие признака, недоступные/неполученные данные,
  копирование, форматирование, таблицы и гостевой поток.
- Адресный ESLint, обычная сборка клиента и SSR/prerender прошли.
- Browser Plugin: учебные данные подтвердили отсутствие дубля до/после входа
  и замочек полезного заголовка с доступом после учебного входа. Затем обычный
  localhost:5173 открыт с обновлённым backend; Ольга выполнила ручную проверку.

Новых платных запросов агент не запускал. Локальный №277 содержит пять heading,
поэтому вкладка у него сохранена правильно. Ольга заметила отсутствие этих
заголовков в production-результате; причина различия не исследована. Эта правка
не меняет генерацию, промпты, OCR, провайдеров и сохранённые результаты.

## Отдельный выпуск

Только данная правка: миграций, новых зависимостей и изменения env нет.
Черновик 049 и незавершённая многостраничность в этот коммит не входят.

Команды выполняет Ольга. После получения отдельного коммита:

```bash
ssh root@147.45.246.205
cd /root/myworld && git pull --ff-only
cd /root/myworld/client && npm run build
pm2 restart myworld-server
curl -fsS http://127.0.0.1:4000/api/health
```

Затем обновить страницу гостя: точный дубль скрыт; полезные заголовки/списки/
таблицы сохраняют замочек; после входа полезное оформление доступно.
Для этой правки `npm run db:migrate` не нужен. Команды выдаются в чате по шагам.
