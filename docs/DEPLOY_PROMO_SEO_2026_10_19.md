# Публикация промо и SEO от 19 октября

Подготовлены тексты о пакетной обработке и таблицах на `/photo-to-text`,
пакетная загрузка и FAQ на `/handwriting-to-text`, ссылки и description.
Новые страницы не созданы. Аналитика, загрузка, тарифы и таблицы как функция
не изменены. Код проверен локально: lint, сборка/SSR/prerender, SEO HTTP 9/9,
браузер 375/1280. Публикацию выполняет Ольга после отдельного решения.

## До публикации

Коммит промо должен быть отправлен в `origin/main`. Если он пока только локально,
команды Ольги в PowerShell:

```powershell
Set-Location C:\Users\olgak\PROJECTS\myworld
git branch --show-current
git log -3 --oneline
git push origin main
```

## На сервере

Сначала проверить рабочую папку:

```bash
cd /root/myworld
git status --short
```

При незакоммиченных изменениях сначала сохранить и разобрать их. После этого:

```bash
cd /root/myworld &&
git pull --ff-only origin main &&
git log -3 --oneline &&
npm run build --prefix client
```

Для этой правки миграции БД и перезапуски backend/nginx не нужны.
Зависимости не менялись. Соседние серверные задачи публикуются по их инструкциям.

## Проверяет Ольга после публикации

1. `/photo-to-text`: после учебного примера видны «Распознайте текст с нескольких
   фото за одну загрузку» и блок таблиц; ссылка «Несколько фото» ведёт к блоку.
2. `/handwriting-to-text`: видны несколько страниц конспекта и четыре ответа;
   ссылка о восстановлении таблиц открывает `/photo-to-text#tables` у блока.
3. Проверить обе страницы на телефоне, открытие учебного фото и переход
   к загрузке. Никаких обещаний объединения страниц или скачивания XLSX нет.
4. Проверить на рабочем инструменте, что актуальная версия действительно
   поддерживает описанные условия пакета и таблиц; агент production не тестирует.
5. В Вебмастере проверить текущую индексацию и причины исключения, затем
   отправить обе обновлённые страницы на переобход. Публикация не означает
   автоматического попадания в индекс.

При необходимости проверить HTTP-ответы вручную:

```bash
curl --fail --silent --show-error https://word2you.ru/photo-to-text -o /dev/null
curl --fail --silent --show-error https://word2you.ru/handwriting-to-text -o /dev/null
```

Не включать Директ или VK автоматически после сборки. Причина отказа запуска
первой группы Директа остаётся отдельной незавершённой проверкой.
