# Приглашение войти после гостевого лимита

17 ноября 2026, согласовано Ольгой. После исчерпания гостевого лимита
показывается один компактный блок:

> После входа — ещё 5 обработок бесплатно  
> и пакетная загрузка фотографий.

Число берётся из действующего публичного лимита. При неизвестном значении
показывается текст без придуманного числа. Затем — приглашение войти и
существующие кнопки способов входа с прежними обработчиками.

Если гостевые фотографии показаны, второй блок входа под ними **сохраняется**.
Если фотографий нет, повторный пустой блок входа не показывается. Другие
ошибки не скрываются. На телефоне нижние кнопки переносятся по строкам.
Квоты, авторизация, пакеты и backend не меняются.

Проверки: профильные publicLimits/guestExperienceRefactor, адресный ESLint,
сборка клиента. Оба состояния реального GuestHome проверены в Browser Plugin
на учебных данных: 1 блок без фото / 2 с фото, 1440px и 390px. Горизонтального
переполнения на телефоне нет. Проверено изменение лимита и неизвестное значение.

## Выпуск

Агент делает коммит и push в origin/main, без подключения к production.
Для публикации Ольга выполняет шаги сама, по одному:

1. Вход: `ssh root@147.45.246.205`.
2. Проверка дерева: `cd /root/myworld && git status --short`.
3. Если дерево чистое: `git pull --ff-only origin main`.
4. Сборка: `cd /root/myworld/client && npm run build`.
5. Проверить в браузере состояние гостя после лимита без фото и с фото;
   наличие точного текста с переносом, кнопок входа, второго блока только
   при наличии фото. Проверить телефон и широкий экран.

Новых зависимостей, миграций и рестарта myworld-server для этой клиентской
правки нет. В env ничего добавлять не требуется. Исходные фотографии,
результаты распознавания и состояние гостевого лимита не изменяются.
Откат: отдельно revert этого коммита и повторная сборка клиента; не откатывать
целиком общую рабочую папку и чужие изменения.
