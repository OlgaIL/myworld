```bash
cd /root/myworld

```

```bash
git pull --ff-only origin main
VITE_CLARITY_ENABLED=true VITE_CLARITY_HOSTS=word2you.ru npm run build --prefix client

```

клиентский состав; обновить страницу после сборки. Параметры Clarity сохранены.
