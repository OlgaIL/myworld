# Подсказка пакетной загрузки — публикация с промо

29 октября 2026. Ольга поручила включить правку в ближайший выпуск промо.

BatchUploadHint использует существующую общую проверку getProcessingPackageOffer.
Ссылка покупки видна при суммарном остатке 0–3, скрыта при большем остатке
и безлимитном доступе. Подсказка загрузки и баланс сохраняются.
Остаток 186 проверен отдельно; четыре существующих теста правила прошли.

Файлы: client/src/components/BatchUploadHint.jsx, BatchUploadHint.css,
подключение в CabinetHome.jsx. Изменений БД и новых зависимостей нет.

Публикация — **обычный Git вместе с промо** по
[общей инструкции](DEPLOY_PROMO_FEATURES_2026_10_25.md).
Старые патчи не применять. Отдельно публиковать эту правку поверх общего
выпуска не нужно. Для неё самой перезапуск не требуется; весь выпуск промо
требует перезапуска из-за серверных публичных маршрутов.

Ольге проверить после Ctrl+F5: при остатке больше 3 покупки под загрузкой нет,
число оставшихся обработок и возможность загрузки сохранены. Не тратить
реальные обработки до порога ради теста. Production агент не проверяет.
