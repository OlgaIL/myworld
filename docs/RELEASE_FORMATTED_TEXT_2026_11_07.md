# Сохранение текста, границ и оформления при копировании — 7 ноября 2026

Подготовлено к публикации Ольгой. Публикация и проверка production ещё не выполнены.

## Изменение

- Готовые строки при показе и копировании сохраняют регистр, пунктуацию и пробелы.
  Автоматическая типографическая правка клиентом отключена.
- Сервер сохраняет одиночные переносы внутри paragraph, CRLF/CR приводит к LF.
  Пустые строки разделяют абзацы. Обычные строки не назначаются заголовками.
  Нормализация пробелов внутри строк, списки и table_source остаются прежними.
- «Оформленный» передаёт text/plain и text/html также для заголовков и абзацев
  без списков/таблиц. В HTML текст экранирован, переносы представлены br.
- Подпись сохранённого OCR — «Исходный (без замен)»; точность OCR по фото не обещается.

Промпты, модель, OCR, лимиты, квоты и БД не менялись. Старые документы не пересчитываются.
Уже склеенный текст без сохранённых границ эта правка не восстанавливает.
Новые платные запросы не запускались, качество реальной новой генерации не проверено.

## Проверка

44 клиентских и 64 серверных теста: абзацы, заголовки, списки, таблицы, символы,
безопасный HTML, исправления, ошибки и сохранение OCR. ESLint и сборка прошли.
На существующих 12 приватных контрольных примерах blocks и cleanText сохранены.
В Browser Plugin проверены пять подставных сценариев и смешанный пример;
реальная кнопка передаёт ожидаемые plain/HTML, браузерный write успешен.
Ольга подтвердила работу локального стенда. Вставка в Word/Excel ещё не подтверждена.
Приватные примеры, исходные документы и диагностические артефакты в выпуск не входят.

## Публикация и откат

Новых зависимостей и миграций нет. После получения согласованного коммита нужны
обычный npm run build в /root/myworld/client и pm2 restart myworld-server.
Inspectlet env уже настроен; переменные перед сборкой повторять не нужно.
Команды Ольга получает непосредственно в чате по одной, после результата предыдущей.
SSH, публикацию и production-проверку агент не выполняет.

После рестарта Ольга проверяет health backend и открывает сайт с обновлением
страницы. На имеющемся документе с заголовками — показать/скопировать/вставить
в Word, сверить границы, регистр и символы; на примере со списком/таблицей —
сохранность пунктов и ячеек. Платную повторную генерацию без согласования не запускать.
Серверная правка действует при последующей обработке, уже склеенные записи не исправляет.

Откат: отдельным git revert отменить именно коммит этого выпуска, собрать клиент
и перезапустить myworld-server. Не восстанавливать общие файлы целиком и не откатывать
соседние коммиты. БД и сохранённые после выпуска документы при откате не переписывать.
