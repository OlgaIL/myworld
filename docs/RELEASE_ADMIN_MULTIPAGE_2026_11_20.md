# Счётчик многостраничных документов в админке

По решению Ольги от 20 ноября считаем текущее содержимое архивов, без истории
удалённых или разделённых документов. Отдельная карточка «Многостраничные сейчас»
расположена рядом с «Записи» в существующем оформлении админки.

Один сохранённый документ с двумя и более страницами даёт единицу независимо
от состояния распознавания. Несохранённые фотографии из очереди не считаются
страницами архива. После разделения, извлечения страниц или удаления число
пересчитывается при следующем обновлении сводки. Фильтры таблицы пользователей
не меняют глобальный показатель.

API `/admin-api/users-summary` возвращает `multipageDocumentsCount` вместе
с прежними полями. Авторизация и запрет кеширования сохраняются. Новых таблиц,
миграций, зависимостей и переменных env нет.

Семь проверок на временной локальной схеме прошли: пустой набор, документы
разной длины, незавершённое распознавание, разделение, удаление, авторизация
и ответ HTTP. Browser Plugin не открыл локальный макет; визуальная проверка
не подтверждена.

Публикация Ольгой после отдельного коммита:

```bash
ssh root@147.45.246.205
```

На сервере:

```bash
cd /root/myworld
git pull --ff-only
npm --prefix client run build
pm2 restart myworld-server
curl -fsS http://127.0.0.1:4000/api/health
```

После успешной сборки и рестарта обновить `/admin-control`: карточка должна
появиться рядом с «Записи». Сверить число с текущими многостраничными
документами. Боевой сервер агент не меняет.
