# Реквизиты и попап — выпуск 18 ноября 2026

Ольга подтвердила локальную проверку реквизитов и поручила включить их
в один выпуск с попапом. Публикацию и проверку на сервере выполняет Ольга.

Изменения:

- Обычный попап всегда по центру, с лупой, уменьшением, поворотом,
  возвратом к целому фото и прокруткой в обе стороны.
- Реквизиты восстанавливаются из координат первого Google OCR после
  единственного штатного LLM-вызова. Число блоков не зафиксировано.
  Исходный OCR сохранён, сомнительные связи/форматы отмечены. Числа ради
  совпадения длины не заменяются, неизвестные национальные профили не
  проверяются по российским правилам. Неизвестные формы идут прежним путём.
- Повтор оформления читает только принадлежащий владельцу кэш с совпадающим
  хэшем изображения; дополнительных OCR/LLM-запросов не добавлено.
- Выключатель `REQUISITE_LAYOUT_ENABLED=false` отключает восстановление
  для следующих обработок. Сохранённые результаты не пересчитываются.

В этот выпуск не входят многостраничность, изменения входа/архива и отдельная
незавершённая правка порядка заголовка заявления.
Схема БД не изменяется. Таблица `document_ocr_layouts` использует уже существующую
миграцию 042; новые миграции этот выпуск не добавляет.

## Команды Ольги на сервере

1. Получить коммит:

```bash
cd /root/myworld
git pull --ff-only origin main
```

2. Включить реквизиты в `server/.env`, сохранив остальные настройки:

```bash
if grep -q '^REQUISITE_LAYOUT_ENABLED=' server/.env; then
  sed -i 's/^REQUISITE_LAYOUT_ENABLED=.*/REQUISITE_LAYOUT_ENABLED=true/' server/.env
else
  printf '\nREQUISITE_LAYOUT_ENABLED=true\n' >> server/.env
fi
```

3. Собрать клиент и перезапустить backend:

```bash
npm run build --prefix client
pm2 restart myworld-server --update-env
```

4. Проверить запуск:

```bash
pm2 status myworld-server
curl -fsS http://127.0.0.1:4000/api/health
pm2 logs myworld-server --lines 40 --nostream
```

После обновления страницы Ольга проверяет попап существующего фото,
затем свою обычную загрузку банковской справки: исходный OCR сохранён,
поля не перемешаны, нули сохранены, сомнительные места отмечены. Проверку
обычного документа без реквизитов также выполняет Ольга. Новую платную
обработку агент не запускает.

## Отключение обработки реквизитов

```bash
cd /root/myworld
sed -i 's/^REQUISITE_LAYOUT_ENABLED=.*/REQUISITE_LAYOUT_ENABLED=false/' server/.env
pm2 restart myworld-server --update-env
```

Это останавливает восстановление для последующих обработок, не меняет
сохранённые результаты и оставляет попап с лупой.
