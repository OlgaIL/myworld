# Копирование таблиц в Word

13 октября исправлено копирование документа: кнопка читает только активную
вкладку. Для таблиц во вкладках «Улучшенный» и «Оформленный» в один элемент
буфера передаются text/plain и text/html с настоящими ячейками и границами.
Обычный текст копируется как прежде. HTML строится из структуры документа,
все пользовательские значения экранируются. Если браузер не может записать
HTML, интерфейс сообщает об ошибке, не выдавая простой текст за таблицу.
API: [Clipboard.write — MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/write).

Проверены 76 клиентских тестов, lint и production-сборка. 13 октября Ольга
подтвердила локальную проверку и поручила подготовить публикацию. После неё
повторить вставку в настольный Word на рабочем сайте.

## Локальная проверка

В документе с улучшением открыть «Текст» и нажать его кнопку копирования:
должен копироваться именно этот вариант. Затем повторить для «Улучшенного»
и «Оформленного»: исправленные числа и таблицы должны совпадать с открытой
вкладкой. В Word вставлять с сохранением исходного форматирования; вариант
«Сохранить только текст» удаляет оформление. Проверить две таблицы, числа
216,8 и 221,0 в таблице 17 и 717,8 за 2028 год в таблице 18.

## Публикация Ольгой

После локальной проверки и отправки утверждённого коммита в origin/main:

```bash
cd /root/myworld
git status --short
```

При изменениях в рабочей папке остановиться и сохранить их перед обновлением.

```bash
cd /root/myworld &&
git pull --ff-only origin main &&
git log -1 --oneline &&
cd client &&
npm ci &&
npm run build
```

Изменены только клиент и документация. Миграции БД и перезапуск backend
для этого исправления не требуются. После сборки обновить страницу сайта,
повторить проверку активных вкладок и вставки обеих таблиц в Word.
