# Подстановка таблиц из списков — 23 октября 2026

Клиент теперь сопоставляет заголовок-список и строки-список с готовой таблицей.
Замена требует совпадения всех строк по подписи и числовому значению,
единственного места вставки и отсутствия лишних элементов списка.
Окружающий текст сохраняется. Сервер и данные не изменяются.

все пять абзацев расчётов после неё остаются без изменений.
