# Сохранённый эталон общей группы — 6 ноября 2026

Решение Ольги: сохранить удачную общую группу как эталон для восстановления
после чужой правки. Каноническая инструкция: docs/DIRECT_GENERAL_CONTROL_REFERENCE.md.
Кампанию не запускали, ничего в рекламе не сохраняли/не меняли.

Файлы:

- reference.json — значения для сравнения и восстановления, IDs, тексты,
  ссылки, ключи, ставки, минусы, категории, наследование, устройства,
  стратегия, дополнительные параметры и текущие статусы.
- ad-editor.txt/png — полный редактор основного объявления.
- group-editor.txt/png — полный редактор группы.
- campaign-editor.txt — исходный вид кампании.
- campaign-strategy-expanded.txt — раскрытая атрибуция стратегии.
- campaign-all-expanded.txt — оба блока дополнительных настроек раскрыты:
  персонализация, мониторинг, минусы, запреты площадок/IP, приоритизация.
- bids.txt — текущие четыре ставки и режим автотаргетинга.
- ads-status.txt/png — исходник остановлен кампанией, два варианта отдельно.
- queries-sample.md — восемь реально прочитанных оплаченных запросов.
- search-queries-visible.txt/png — подтверждение выборки и общего итога.
- manifest.sha256.json — хеши файлов этого снимка и канонической инструкции.

Датированную папку не обновлять новыми настройками. Для следующего согласованного
состояния создать новую папку, сохранив эту в Git-истории. Полные значения UI
сверять с reference.json и текстовыми срезами, а не только с превью/скриншотом.
Снимок не является автоматически импортируемым архивом Яндекс Директа и не
сохраняет внутреннее состояние аукциона или прежнюю опубликованную посадочную.
Прежний результат возвратом настроек не гарантируется.
