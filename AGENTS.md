- Work only in the main project folder: `C:\Users\olgak\PROJECTS\myworld`.
- Do not create Git worktrees, duplicate project folders, or separate local copies unless Olga explicitly asks for one.
- For branch work, use the same project folder with `git switch`. Check `git status` before switching and preserve all uncommitted changes.
- If parallel work genuinely requires a separate worktree, explain why and ask Olga for permission before creating it.
- Never deploy to or test production. Olga performs production deployment and production verification herself.
- After local verification, always provide Olga with exact deployment, migration, restart, and production-check commands relevant to the change.
- Keep `docs/ROADMAP.md` current when Olga adds, removes, completes, or reprioritizes project work. Do not mark an item complete without verification.
